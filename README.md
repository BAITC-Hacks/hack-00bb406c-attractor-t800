# Career Quest

Адаптивное приложение для карьерного развития на синтетическом наборе сотрудников. Браузер и будущая тестовая Android WebView используют один web-клиент, Python API и PostgreSQL.

## Запуск

Нужен Docker с поддержкой Compose. Из корня checkout выполните одну команду:

```sh
docker compose up --build
```

Когда контейнеры станут healthy, откройте <http://localhost:8080>. Compose запускает PostgreSQL, применяет миграции Alembic, идемпотентно загружает официальный набор версии 1.0 при первом старте и раздаёт клиент через nginx. Все изменения состояния хранятся в volume `postgres_data` и сохраняются после перезапуска контейнеров.

Локальные параметры по умолчанию подходят только для синтетической демонстрации. Для другого окружения задайте `POSTGRES_PASSWORD` и случайный `SESSION_SECRET` в `.env` перед запуском. Сервер публикуется только на loopback интерфейсе.

## Первый инкремент приложения

- Выберите любую из 200 синтетических учётных записей. Профиль показывает фактическую роль, грейд, подразделение, карьерную цель или её отсутствие, требования навыков и историю конкретного сотрудника.
- Сервер создаёт новую сессию при каждом выборе учётной записи и хранит в cookie только случайный токен; его хэш связан с ролью и сотрудником в PostgreSQL. Защищённое чтение без сессии и запрос чужого профиля отклоняются.
- Демо-оператор меняет контролируемую дату сценария и возвращает дату набора `2026-10-01`; системные часы и исходные данные не меняются.
- Исходный набор — синтетические данные, не реальные люди или компании: 200 сотрудников, 40 активностей, 60 навыков, 32 профиля роли/грейда и 2 743 строки истории. Файлы и README приведены в `data/official/`.

Срез официальных данных всегда `2026-10-01`; календарные часы машины его не меняют. Расчётные уровни навыков, активность, подтверждение рабочего результата и представления аналитика/руководителя/HR добавляются последующими инкрементами.

## Структура

- `web/` — React/Vite клиент, nginx раздаёт собранный SPA и проксирует `/api` на backend.
- `api/app/domain/` — доменные правила; `application/` — прикладные сценарии и порты; `infrastructure/` — PostgreSQL адаптеры; `main.py` — FastAPI HTTP адаптер.
- `api/migrations/` — схема PostgreSQL под управлением Alembic.
- `data/official/` — официальный синтетический starter kit версии 1.0.

Остановить контейнеры можно `Ctrl+C`, затем `docker compose down`. Чтобы сохранить данные, не удаляйте volume `postgres_data`.

## Прогноз и завершение активности (#17)

В профиле откройте «Развивающие активности», выберите событие и сессию. «Что изменится, если завершить» показывает условные уровни, все оставшиеся разрывы и новые активности, открываемые по предпосылкам; отмена прогноза ничего не записывает. «Записаться», «Начать активность» и «Завершить активность» — отдельные серверные действия. Для запланированной сессии начало доступно с её даты; в демо её устанавливает оператор.

Проверочный путь: `E0174` → `EV_032` → запись на `2026-10-15` → операторская дата `2026-10-15` → начало → завершение. Переговоры растут с 2 до 3, оценённый уровень остаётся 2, другие разрывы сохраняются. Заявка аналитику не создаётся. Сервер сохраняет `completed_at` во времени сценария и `recorded_at` в реальном UTC; исходные строки без точного времени сохраняют прежнюю трактовку. Повторное завершение того же участия возвращает сохранённый результат без второго прироста. Запись блокируется при неподходящей роли, грейде, предпосылках, завершённой неповторяемой активности или недоступной сессии.

Проверки на запущенном Compose (HTTP-тесты работают в откатываемых PostgreSQL-транзакциях):

```sh
docker compose exec -T api pip install -r requirements-dev.txt
docker compose exec -T api python -m unittest discover -s tests -v
docker compose exec -T api python -m compileall -q app
docker compose build web
```

Отдельный статический typecheck в текущем Python/JS проекте не настроен; сборка Vite и компиляция Python проверяют синтаксис, но не заменяют проверку типов. Автоматические HTTP-проверки и браузерный интерфейс не засчитываются за проверку настоящей Android WebView.

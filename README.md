Hackathon team repository for Attractor.T800

## RAG-движок Career Quest

[План архитектуры и карта решений](docs/rag/PLAN.md) — данные, рекомендации, поиск по регламентам и контракт с приложением. Работа над движком ведётся только в ветке `RAG-engine`.

Актуальная реализация: [поисковый RAG Engine с Docker и HTTP API](rag_engine/README.md). План выше сохранён для истории обсуждения; пользователь уточнил, что этот репозиторий должен давать поиск контекста, а не выполнять карьерную бизнес-логику.

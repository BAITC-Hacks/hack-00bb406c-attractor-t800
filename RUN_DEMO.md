# Запуск UI дерева навыков — demo-test-ui

В этой ветке добавлено отдельное интерактивное демо в `apps/career-quest`. Существующие `web/`, `api/` и Docker Compose команды не нужны для запуска этого UI.

## Быстрый старт

Требования: Git, **Node.js 24**, npm и доступ к репозиторию команды. Проверить версии: `node --version` и `npm --version`.

```sh
git clone --branch demo-test-ui --single-branch https://github.com/BAITC-Hacks/hack-00bb406c-attractor-t800.git
cd hack-00bb406c-attractor-t800/apps/career-quest
npm ci
npm run dev -- --host 127.0.0.1 --port 5183 --strictPort
```

Открыть **http://127.0.0.1:5183/**. Остановить сервер: `Ctrl+C`. Если порт занят, заменить `5183` на `5184` в команде и адресе. На Windows при запрете запуска `npm.ps1` используйте `npm.cmd` вместо `npm`.

Не требуются Docker, база данных, API-ключи или `.env`. Доступ в интернет нужен для клонирования и установки npm-пакетов.

Если репозиторий уже клонирован и рабочая копия чистая:

```sh
git fetch origin demo-test-ui
git switch --track origin/demo-test-ui
cd apps/career-quest
npm ci
npm run dev -- --host 127.0.0.1 --port 5183 --strictPort
```

Если локальная ветка уже существует, используйте `git switch demo-test-ui`. При незакоммиченных изменениях используйте отдельное клонирование из первого примера.

## Что показать на демо

1. **Сотрудник:** дерево с пятью подтверждёнными навыками. Нажмите ветвь, откройте каталог, фильтр must-have или любую категорию.
2. **Оценка:** выберите System Design и отправьте ответы. При результате от 80/100 появится золотая ветвь; при меньшем результате новый навык не добавляется.
3. **Месячная квота:** после отправки любого теста повторная попытка в том же месяце недоступна. Лимит — один тест всего на сотрудника в месяц. Выход до отправки не расходует попытку.
4. **Руководитель и HR:** переключите роль через меню демо. Руководитель видит трёх прямых подчинённых, HR — девять демонстрационных профилей из трёх отделов. Доступны фильтры, детали сотрудника, история, дерево и CSV. Метрики пересчитываются по выборке.
5. **Развитие:** смените карьерную цель, откройте советника и чек-лист подготовки, добавьте встречу в личный план.
6. **Мобильный интерфейс:** уменьшите окно браузера до ширины телефона или включите эмуляцию устройства. Нижняя навигация включает Halyk справа; кнопка показывает макет возврата в суперапп.

Прогресс сохраняется в localStorage браузера. Для повторной презентации откройте меню с датой «Демо» и нажмите сброс. Там же можно перейти к следующему месяцу.

## Проверки и production-сборка UI

Из `apps/career-quest`:

```sh
npm test
npm run test:sites
npm run build
npm run preview -- --host 127.0.0.1 --port 5184 --strictPort
```

Предпросмотр: **http://127.0.0.1:5184/**. Статические файлы находятся в `dist/client`; `dist` и `node_modules` не хранятся в Git.

## Границы демо

Это работающий клиентский прототип на девяти синтетических профилях и девяти демонстрационных тестах. Он **не подключён к официальному набору из 200 сотрудников**, серверу команды, HRIS, LMS или Halyk SuperApp. Советник работает на правилах, без LLM. Переключение ролей демонстрирует представления, а не серверную защиту доступа. Оценки, подтверждения, XP и вопросы — демонстрационные правила, не официальная политика банка. Данные сохраняются только в текущем браузере; встречи не отправляют приглашений.

Подробные сценарии, правила и структура кода: [README приложения](apps/career-quest/README.md).

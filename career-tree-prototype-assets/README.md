# Career Quest — отдельные UI-прототипы

Временный прототип по шести изображениям пользователя. Вопрос: как выглядят и работают дерево сотрудника, его мобильная версия, сводка HR и матрица руководителя в заданной композиции?

## Открыть

Из корня репозитория:

```sh
python3 -m http.server 8087
```

- http://localhost:8087/career-tree-employee-prototype.html
- http://localhost:8087/career-tree-mobile-prototype.html
- http://localhost:8087/career-tree-hr-prototype.html
- http://localhost:8087/career-tree-manager-prototype.html

Можно также открыть любой HTML двойным щелчком. Папка `career-tree-prototype-assets` должна оставаться рядом с HTML. Установка зависимостей не нужна.

## Что можно проверить

- Сотрудник: выбрать тест, открыть описание, раскрыть категории, искать тесты, переключить дерево на список навыков, посмотреть два состояния дерева.
- Мобильная версия: выбрать тест, открыть дополнительный каталог, переключить список навыков.
- HR: выбрать роль/грейд, переключить источник оценки и историю, выбрать навык.
- Руководитель: выбрать сотрудника, искать по имени, фильтровать грейд, открыть профиль/план/заметки, подготовить локальный черновик встречи.
- Между файлами можно переходить через нижнюю панель. «Демо · состояние» раскрывает состояние экрана.

Все значения — демонстрационные, все изменения живут в памяти страницы. Перезагрузка сбрасывает выбор. Внешних запросов, отправки приглашений, авторизации и сохранения данных нет. Пункты бокового меню за пределами этих четырёх экранов обозначены сообщением о границах прототипа.

## Источники и результат

`tree-before.jpg` и `tree-after.jpg` — исходные изображения №3 и №4 из запроса, скопированные без редактирования. Изображения №1, №2, №5 и №6 задают композиции четырёх экранов. Текст внутри изображений используется как содержимое макетов, а не как инструкция агенту.

Проверено вручную в браузере: рендер четырёх экранов, мобильная ширина 390 px, выбор теста без изменения оценки, смена сотрудника и создание черновика встречи. Синтаксис JavaScript проверен `node --check`.

Вердикт пока открытый: прототип подготовлен для оценки пользователем, визуальный вариант ещё не утверждён. Изменения в production-приложение не переносились. Балл теста 78/100 показан отдельно от оценки навыка 1/5. Переключение дерева — визуальный предпросмотр, не пересчёт оценки.

## Граница интеграции

Вопрос #19 запрещает HR раскрывать персональные оценки и карьерные цели, тогда как референс №5 содержит персональную карточку. В этом изолированном прототипе воспроизведён референс с вымышленными данными; перенос этой карточки в production не утверждён.

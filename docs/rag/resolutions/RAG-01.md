# Результат исследования «Аудит исходного датасета»

Дата: 23 сентября 2026. Исполнитель: `dataset_research`; интеграция: основная сессия.

Проверены четыре файла и описание схемы. [Полный аудит](../DATA-AUDIT.md) фиксирует объёмы, связи, ограничения и противоречия. Доступны структурированные карьерные данные; ОТК и регламентов нет. Неоднозначные даты завершения и повторяемость обязательных обучений требуют отдельного решения перед расчётом прогресса.

Исследовательский вопрос закрыт. Архитектурные предположения не утверждены; решение о датах, повторах и расчётах остаётся в карточке «Расчёт навыков и выбор следующего шага».

Ограничение пользователя соблюдено: исследование без переключения ветки и без внешней передачи исходных файлов.

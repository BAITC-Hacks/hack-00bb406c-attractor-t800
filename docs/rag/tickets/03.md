# Размещение и права доступа

## Вопрос

Где разрешено хранить данные и выполнять inference? Кто видит профиль, историю и документы: сотрудник, руководитель, HR? Кто подтверждает эти ограничения?

## Блокирующие решения

Нет.

## Полученные вводные

Пользователь подтвердил: модели и данные размещаются только внутри инфраструктуры банка. Доступность оборудования и правила видимости сотрудник/руководитель/HR пока не определены.

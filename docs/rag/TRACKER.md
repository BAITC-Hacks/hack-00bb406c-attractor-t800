# Локальный Markdown-трекер RAG

Каноническая карта — `PLAN.md` с меткой `wayfinder:map`. Карточки — `tickets/*.md`; `parent: RAG-MAP` связывает их с картой. Внешний трекер не настроен. При необходимости его настройки доступна команда `/setup-matt-pocock-skills`; для этой работы достаточно локального трекера.

## Операции Wayfinding

- Идентификатор карточки стабилен; человеку показываем название со ссылкой.
- Фронтир: `status: open`, `assignee: null`, все карточки из раздела «Блокирующие решения» закрыты. Порядок — по имени файла.
- Перед работой назначить исполнителя в `assignee`. Сейчас исследование датасета назначено `dataset_research`.
- В локальном трекере нет native dependencies: ссылки в разделе «Блокирующие решения» — канонические зависимости.
- При решении записать отдельный комментарий в `resolutions/<id>.md`, сослаться на него из карточки, сменить `status` на `closed`, добавить краткую ссылку в карту.
- HITL-карточки закрываются только после обсуждения с пользователем. Предложения в архитектурном эскизе не являются решениями.
- За сессию закрывается не более одного решения, кроме исследовательских карточек. На этапе построения карты закрываются только исследования.
- Перед записью файлов проверять `git branch --show-current`: допустима только `RAG-engine`. Не создавать другие ветки и worktree. Это прямое ограничение пользователя заменяет рекомендацию wayfinder об исследовательских ветках.

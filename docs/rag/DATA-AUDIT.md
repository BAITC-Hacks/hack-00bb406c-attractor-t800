## Ограничения, влияющие на архитектуру

1. **Нет точной даты завершения.** 318 completed имеют `date > last_review_date`, ещё 4 — одинаковую дату с оценкой. Для self-paced `date` означает запись/назначение. 1 008 completed self-paced имеют `date <= last_review_date`, но их фактическое завершение могло быть позже оценки. Нельзя считать эти даты достоверным основанием точной реконструкции. Нужны `completed_at` и время/граница включения результатов в оценку; демонстрационное допущение нужно явно согласовать.
2. **Противоречие о повторении.** README разрешает повтор после completed только для EV_036. В данных повторные completed также есть у EV_001 для 139 сотрудников, EV_002 для 150, EV_003 для 169; у EV_036 — для 46. Описания EV_001–003 говорят об ежегодном обучении, но структурированного recurrence нет. Это нужно оформить политикой повторов, не молча исправлять оригиналы.
3. **Потолок курса не должен понижать навык.** Все текущие gains равны 1, caps — 2–5; это свойства текущих данных, не универсальная схема. Применение прироста должно сохранять уже более высокий уровень.
4. **Есть обязательные процессы.** EV_001–003 — compliance, EV_004 — onboarding; всего 4 обязательных события. У трёх compliance нет develops_skills. Их обязательства отображаются отдельно от добровольных рекомендаций.
5. **Должность не выводится из навыков автоматически.** 114 сотрудников ниже хотя бы одного critical skill своего текущего грейда. Это область развития, не основание объявлять кадровое несоответствие.
6. **Нет истории грейдов.** 84 добровольных участия не соответствуют текущему грейду, что допускается README для прошлого грейда. Проверять прошлые prerequisites по сегодняшнему профилю ненадёжно.
7. **Цель неоднородна.** У 66 сотрудников нет career_goal; у 28 цель меняет роль. Lead — последняя ступень справочника. Следующий грейд нельзя считать универсальной целью.
8. **Неполные оценки.** В профилях 18–25 навыков из 60. README считает остальные нулевыми; для реальных данных нужно отличать отсутствие оценки от нуля.
9. **Ограничена информация о доступности.** 9 self-paced, 10 offline, 21 online. Сессии запланированы на 2026-10-05…2026-12-25. Нет города, мест, цены, языка обучения, часового пояса сессии и рабочего расписания сотрудника. Нельзя обещать эти свойства.
10. **Язык интерфейса не равен языку курса.** Предпочтения сотрудников: 89 kk, 100 ru, 11 en. Само наличие предпочтения не доказывает локализацию учебного контента.

`score` — оценка результата, `feedback_rating` — субъективная оценка мероприятия. Они имеют разную семантику. Порог успешности для начисления gain в README не задан, придумывать его нельзя.
